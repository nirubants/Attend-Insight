# Attend-Insight

Attend-Insight is a comprehensive attendance management and academic intervention platform. It features distinct portals for different roles (Admin, IT Admin, Faculty, and Advisor) and uses a backend designed for performance and reliability.

## Features

- **Role-based Portals**: Dedicated interfaces for Faculty, Advisors, IT Admins, and system Admins.
- **Dynamic Dashboards**: Real-time visualization of attendance, student performance, and risk metrics.
- **Attendance System**: Robust backend tracking session requirements and academic interventions.

## Setup

1. Make sure you have Node.js installed.
2. Navigate into the backend directory:
   ```bash
   cd attendinsight-backend
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: SQLite / PostgreSQL (configured via db.js)
